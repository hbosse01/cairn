# Cairn

Application web (installable sur téléphone) de suivi sportif de Henri : santé et récupération, séances, planning, charge, courses et tests labo.

- Données : Suunto et Strava via Intervals.icu (clé API saisie dans l'app, stockée uniquement sur le téléphone).
- Calendrier des courses et plan d'entraînement : Google Sheets partagés en lecture.
- Code : HTML/CSS/JavaScript sans étape de build, Chart.js inclus dans `vendor/`.
- Hébergement : GitHub Pages.
